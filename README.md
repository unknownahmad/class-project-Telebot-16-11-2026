# TgBotSample

A minimal Telegram bot built with `pyTelegramBotAPI` and OpenAI.


## Commands & Triggers

- `/start` — Greet the user
- `help`, `🤍`, `how are you?` — Canned replies
- `country` — Random country from `countries.txt`
- `number` — Random number from `numbers.txt`
- `i want to talk to ai` — Start AI chat mode (`bye` to exit)
